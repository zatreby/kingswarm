# Kingswarm

A hero-plus-swarm action game prototype. One HTML file, no build step beyond wrapping it for hosting.

- Play: https://zatreby.github.io/kingswarm/
- `kingswarm.html` is the source (an artifact fragment: title, style, body). `./build.sh` wraps it into `docs/index.html` for GitHub Pages.
- Modes: ranked vs scaling AI, practice, couch 2-player (arrows or gamepad), online with a friend by link (peer-to-peer via PeerJS).

Controls: WASD move, Shift dash, hold mouse to fire your swarm, Q and R abilities, F or right-click recall, C camera toggle, M sound.
